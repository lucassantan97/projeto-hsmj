# **App Name**: FleetWise AI

## Core Features:

- Real-time Fleet Tracking: Monitor vehicle locations and status in real-time.
- AI-Powered Maintenance Analysis: Automatically extract data from maintenance receipts using Gemini Vision tool, pre-filling form fields for faster logging and analysis.
- Predictive Maintenance: Analyze vehicle data to predict maintenance needs and prevent downtime.
- Group Management: Organize vehicles into groups based on criteria like department or location.
- Sales Tracking: Log vehicle sales, track revenue, and manage sales history.
- BI Dashboard: Visualize fleet performance with interactive charts and key metrics.
- AI Sales Ad Generator: Generate engaging sales ads based on vehicle data using the Gemini LLM tool.

## Style Guidelines:

- Primary color: Deep navy blue (#1E3A8A) to convey trust and professionalism.
- Background color: Light gray (#F9FAFA) to create a clean and modern interface.
- Accent color: Electric blue (#0EA5E9) to highlight key actions and data.
- Headline font: 'Space Grotesk', a modern sans-serif for headers; Body font: 'Inter', a grotesque sans-serif for main texts
- Code font: 'Source Code Pro' for displaying code snippets.
- Use clear, minimalist icons from FontAwesome to represent vehicle functions.
- Maintain a clean, card-based layout for vehicle information and data visualization.
